# Estatutos de Network Theory Applied Research Institute, Inc.

**P1-001 · Versión 1.0 · 2026-08-31 — [P1-001_Bylaws_v1.0.md](P1-001_Bylaws_v1.0.md)**

Preparados y adoptados por la junta fundadora como acto de arranque conforme al
§16.1, y registrados en el registro de gobernanza conforme al §9.5. Como todo
acto de arranque, permanecen abiertos a la membresía conforme al §2.3.

La numeración de versiones se reinicia en 1.0: este es el primer instrumento
redactado conforme a la
[Arquitectura de Doble Faz](https://github.com/NTARI-RAND/Janus), y sustituye la
línea P1-001 v6.0 a v8.0, la cual queda
[archivada y no enmendada](Historical%20Docs/).

## Qué hace este instrumento

JFA asigna a NTARI un asiento preciso: el nivel de protocolo de la capa de
Gobernanza — una organización sin fines de lucro, 501(c)(3), de custodia de
software copyleft. Estos estatutos la rigen. Conforme al §1.4, el Instituto
existe para conservar, mantener y enmendar el documento oficial de JFA y su conjunto
ejecutable de pruebas de conformidad; para custodiar el software JFA como un bien
común de software libre bajo términos copyleft; para investigar sistemas de red,
infraestructura deliberativa y economía endógena; y para educar al público en
esas mismas materias.

## Instrumentos definidos

El §1.5 define tres instrumentos que están fuera de este repositorio:

| Término en los estatutos | Dónde se encuentra |
|---|---|
| «el documento oficial» | [`janus-facing-architecture.md`](https://github.com/NTARI-RAND/Janus/blob/main/janus-facing-architecture.md) en NTARI-RAND/Janus |
| «las doce líneas» | la sección del documento oficial titulada *The Lines That Cannot Be Crossed* |
| «el diseño de mecánica de disputas» | `jfa-dispute-mechanics.md`, conservado en el almacén de documentos de NTARI; aún no publicado |

El texto adoptado se consigna aquí byte por byte, tal como fue adoptado. Dos de
sus enlaces (`../JFA/janus-facing-architecture.md` y
`../JFA/jfa-dispute-mechanics.md`) solo se resuelven dentro del almacén de
documentos de NTARI, no en este repositorio; la tabla anterior es la remisión
permanente para quienes lean aquí. El texto no se edita para repararlos, porque
un instrumento adoptado se enmienda conforme al Artículo XV, nunca se parchea.
