# Bylaws of Network Theory Applied Research Institute, Inc.

**P1-001 · Version 1.0 · 2026-08-31 — [P1-001_Bylaws_v1.0.md](P1-001_Bylaws_v1.0.md)**

Prepared and adopted by the founder board as a bootstrap act under §16.1 and
recorded in the governance registry under §9.5. Like every bootstrap act, it
stands open to the membership under §2.3.

Version numbering restarts at 1.0: this is the first instrument written to the
[Janus Facing Architecture](https://github.com/NTARI-RAND/Janus), and it
supersedes the P1-001 v6.0 through v8.0 line, which is
[archived rather than amended](Historical%20Docs/).

## What this instrument does

JFA assigns NTARI a precise seat — the protocol tier of the Governance layer: a
nonprofit, 501(c)(3), copyleft software stewardship organization. These bylaws
govern it. Under §1.4 the Institute exists to hold, maintain, and amend the
official JFA document and its executable conformance suite; to steward JFA
software as a free software commons under copyleft terms; to research network
systems, deliberative infrastructure, and endogenous economics; and to educate
the public in the same.

(`../JFA/janus-facing-architecture.md` and `../JFA/jfa-dispute-mechanics.md`)
