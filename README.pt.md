# Estatuto do Network Theory Applied Research Institute, Inc.

**P1-001 · Versão 1.0 · 2026-08-31 — [P1-001_Bylaws_v1.0.md](P1-001_Bylaws_v1.0.md)**

Preparado e adotado pelo conselho fundador como ato de arranque (bootstrap)
conforme o §16.1 e registrado no registro de governança conforme o §9.5. Como
todo ato de arranque, permanece aberto à associação conforme o §2.3.

A numeração de versões reinicia em 1.0: este é o primeiro instrumento redigido
conforme a [Arquitetura de Dupla Face (Janus Facing Architecture)](https://github.com/NTARI-RAND/Janus),
e substitui a linha P1-001 v6.0 a v8.0, que foi
[arquivada em vez de emendada](Historical%20Docs/).

## O que este instrumento faz

A JFA atribui à NTARI um assento preciso — o nível de protocolo da camada de
Governança: uma organização sem fins lucrativos, 501(c)(3), de curadoria de
software copyleft. Este estatuto a rege. Conforme o §1.4, o Instituto existe
para deter, manter e emendar o documento oficial da JFA e seu conjunto
executável de testes de conformidade; para zelar pelo software JFA como um comum
de software livre em termos copyleft; para pesquisar sistemas de redes,
infraestrutura deliberativa e economia endógena; e para educar o público
nesses mesmos temas.

O §1.5 define três instrumentos que estão fora deste repositório:

| Termo no estatuto | Onde se encontra |

| "o documento oficial" | [`janus-facing-architecture.md`](https://github.com/NTARI-RAND/Janus/blob/main/janus-facing-architecture.md) em NTARI-RAND/Janus |
| "as doze linhas" | a seção do documento oficial intitulada *The Lines That Cannot Be Crossed* (As linhas que não podem ser cruzadas) |
| "o desenho de mecânica de disputas" | `jfa-dispute-mechanics.md`, mantido no repositório de documentos da NTARI; ainda não publicado |

O texto adotado está registrado aqui byte a byte, tal como foi adotado. Dois de
seus links (`../JFA/janus-facing-architecture.md` e
`../JFA/jfa-dispute-mechanics.md`) só funcionam dentro do repositório de
documentos da NTARI, não neste repositório — a tabela acima é o redirecionamento
permanente para quem lê aqui. O texto não é editado para corrigi-los, porque um
instrumento adotado é emendado conforme o Artigo XV, nunca remendado.
