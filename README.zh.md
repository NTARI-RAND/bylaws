## 本文件的作用

JFA 为 NTARI 指定了一个明确的席位——治理层的协议层级：一个非营利、
501(c)(3)、copyleft 软件托管组织。本章程即对其加以管辖。依 §1.4，本院存在的
目的是：持有、维护并修订 JFA 正式文件及其可执行的合规测试套件；以 copyleft
条款将 JFA 软件作为自由软件共有物予以托管；就网络系统、审议性基础设施与内生
经济学开展研究；以及就上述同样内容对公众进行教育。

修订，绝不打补丁。
